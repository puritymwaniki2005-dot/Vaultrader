# TradeNovaX React source import (staged)

This directory is a staging copy of key files from the prepared React source archive. It is intentionally isolated from the current live website so incomplete source transfer cannot break the existing trading experience.

Included so far:
- React application entry point
- Mkorean-inspired theme stylesheet
- Dashboard component snapshot

**This is not yet a standalone buildable app.** The remaining source modules, public assets, configuration, and dependency manifest must be transferred before building or switching production traffic. The prepared archive is available as a separate handoff; production environment files and secrets must not be committed.
